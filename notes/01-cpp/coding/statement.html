C++ 程序由语句构成：声明语句、表达式语句、控制流语句（if/for/while）——每条语句以分号结尾，默认从上到下顺序执行。

FAQ 常见问题 ​

  1. 语句是什么？

    查看答案

    程序执行的最小单元：一条语句做一件事，以分号 ; 结尾，默认从上到下顺序执行。之前 hello 程序里：

    cpp
    std::cout << "Hello CMake";   // 一条表达式语句
return 0;                     // 一条跳转语句

  2. 声明语句和表达式语句怎么区分？

    查看答案
    • 声明语句：以类型名开头，声明新变量——int x = 5;
    • 表达式语句：在已有变量/对象上做操作，末尾加分号——x = 5;（赋值）、func();（调用）

    记忆：第一次出现某个名字时是声明，之后再用是表达式。

  3. 复合语句（语句块）有什么用？

    查看答案

    用 { } 把多条语句打包成一条，语法上当作单条语句使用——if/for 的函数体、函数定义体都靠它：

    cpp
    if (x > 0) {          // if 后面只能跟「一条」语句
  std::cout << x;     // 打包后两条当一条用
  x = 0;
}

    块还会开启新的作用域：块内声明的变量出块即销毁。

  4. 控制流语句有哪些？

    查看答案

    三类，用来改变「顺序执行」：

    1. 选择：if / else if / else（条件分支）、switch（多值匹配）
    2. 循环：for（计数循环）、while（先判断后执行）、do-while（先执行后判断）
    3. 跳转：break（跳出循环/switch）、continue（跳到下一次循环）、return（返回函数并带回返回值）

    组合起来就是程序的所有逻辑骨架。

  5. main 里的 return 0 是什么意思？

    查看答案

    main 是程序入口，它的返回值交给操作系统：0 表示正常结束，非 0 表示出错——命令行脚本、CI 会据此判断程序成败。

    现代 C++ 里 main 不写 return 时编译器会自动补 return 0;。

  6. 漏写分号会怎样？

    查看答案

    编译报错（C 开头语法错误），因为编译器靠 ; 判断一条语句的边界；漏写会把它和下一行拼成一条，报错位置常常在下一行——「报错看行号，但原因看它前面」。

    例外：以 } 结尾的语句块后面不需要分号；预处理指令（#include）后面也从不加分号。
