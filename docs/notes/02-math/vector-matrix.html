① 向量写法 ​

|v| = √(3² + 4²) = 5 · 矩阵写法（高级）：把向量看作 1×3 / 3×1 矩阵，方便与变换矩阵运算 行向量（1×3 矩阵）
v = [ x y z ]
横着写：1 行 3 列

v = (3, 4, 0) 列向量（3×1 矩阵）★ 推荐

转置（Transpose）
vᵀ：行 ↔ 列互换

② 向量运算（基础六则） ​

加法减法数乘
a + b = (ax+bx, ay+by, az+bz)a − b = (ax−bx, ay−by, az−bz)k·a = (k·ax, k·ay, k·az)
对应分量相加；几何上 = 平行四边形法则= a + (−b)；箭头从 b 端指向 a 端长度缩放 |k| 倍；k < 0 反向
取模规范化（Normalize）点乘（数量积）
|a| = √(ax² + ay² + az²)â = a / |a|a·b = ax·bx + ay·by + az·bz
向量的长度；恒 ≥ 0，零向量模为 0单位向量：长度归一化为 1，只保留方向= |a||b|cosθ；结果是标量，判夹角/投影/同向

③ 叉乘（向量积）—— 仅 3D 向量 ​

a × b 是向量：垂直于 a、b 所在平面叉乘计算公式（3×3 行列式展开）：
长度 |a×b| = |a||b|sinθ —— 恰好等于 a、b 围成的平行四边形面积| i j k |
a × b = | ax ay az |
| bx by bz |

如何区分左手系 / 右手系：

右手系：右手四指从 a 弯向 b（< 180°），拇指指向即 a×b 方向（图形学默认）= i·(ay·bz − az·by) − j·(ax·bz − az·bx) + k·(ax·by − ay·bx)
左手系：按左手同样动作，a×b 方向相反x 分量 = ay·bz − az·by y 分量 = az·bx − ax·bz（带负号） z 分量 = ax·by − ay·bx
自检口诀：x̂ × ŷ = ẑ（右手系）记忆：分量循环『十字相乘相减』；y 分量因行列式展开带 − 号，最容易抄错

验证：写完后用 (1,0,0)×(0,1,0) = (0,0,1) 自测；任意向量 × 自身 = 零向量

④ 踩坑记录 ​

· 用 double 不用 float（渲染累积误差出噪点） · 归一化零向量会除零 → NaN：先 near_zero() 判断兜底
· 叉乘 y 分量符号最易抄错 → 用 x̂×ŷ=ẑ 自测 · 点乘判断朝向记得先归一化，否则数值无意义
