# FAQ 常见问题

1. 为什么从 CPU 光线追踪开始，而不是直接学 GPU？

   离线渲染把像素写进文件，没有窗口/GPU 负担，先把数学和算法吃透。

2. 为什么光线追踪和光栅化都要学？

   两条主流路线互补，阶段 4 做双后端对照渲染，同一场景两种实现互相验证。

3. 每阶段的参考资料是什么？

   阶段 0 自写数学库；阶段 1 Ray Tracing in One Weekend 三部曲；阶段 2 tinyrenderer；阶段 3 learnopengl.com。
